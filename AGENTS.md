# Goobs Games project instructions

Before any collection-wide UI or consistency work, read `games/readme/Navigation-Exceptions.txt`.
Those are explicit user-approved exceptions. Preserve pause-only navigation, integrated action rows, the Woodpile Classic/Shapes selector, Garden Swap's accepted buttons, and Double Take's accepted fullscreen/return behavior unless Glenn explicitly overrides a rule.
Use the visible label `Exit` throughout the collection.
Do not change game rules or balance as part of a layout task without user authorization.
For manual GitHub uploads, deliver one ZIP unless it contains more than 100 items; split larger updates into ZIPs with at most 100 items each; include required shared assets and update offline cache versions.
