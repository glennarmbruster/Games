INSTALL BATCH 4
Extract this ZIP into the existing site root, merging folders and replacing the included files. Do not replace or delete the entire games or shared folder. Upload sw.js too. Open the site online and accept its Update available prompt. Existing saved games remain in the browser.

Install after Batches 1–3. This is an update package, not a standalone site.
