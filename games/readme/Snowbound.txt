Snowbound 0.09.0 — early gameplay revision

Install the ZIP at the Goobs Games root, preserving folders. Existing scores and upgrades carry forward.

Fixes: steering matches finger movement and keyboard direction; decorative mountains are kept outside the playable course; hitting an obstacle ends a Launch & Glide run unless armor absorbs it. Both modes now move faster, with a closer camera, snow spray, track marks, brighter mountain backdrop, and a new icon.

This is still an early game, not a finished 1.0.
