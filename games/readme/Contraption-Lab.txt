CONTRAPTION LAB — VERSION 1.0.3

Upload all ZIP contents to the repository root, preserving games/contraption/.
This update adds one game to the Puzzles tab and its dedicated offline cache group.
12 authored challenges are followed by deterministic generated workshop levels.
The workshop art and game code are local; no network or third-party scripts are required.
Saved progress uses localStorage key contraption.lab.v1.

PLAY
Drag a part from the tray to a numbered mount, or tap part then mount.
Tap a mounted part to turn it. Drag a mounted part to another mount to swap.
Run checks the chain, stopping at the first failed link.
Use Hint for the next missing/incorrect component.

VERSION NOTE
Run advances each link on an independent timer and displays the ball in a
separate animated layer. A canvas frame cannot stall the result.
The offline cache is explicitly versioned at 1.0.3.

The mechanics are an authored chain-reaction puzzle. Ball travel and part
activation are deterministic animation, not a general-purpose physics sandbox.

1.0.2: Smoother continuous animation on the display clock and a new
full-bleed workshop icon. No puzzle rules or saved progress changed.
1.0.3: Rebuilt Run progression to finish even when canvas animation stalls.
This package contains Contraption Lab only; Pool is not included.
