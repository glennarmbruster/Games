# Strike Alley material refresh

`lane-grain-v1.webp` is a local 512px photographic wood-grain texture generated with OpenAI image generation for this development pass. It is shared by provenance with Get Out's neutral wood material, copied here so the bowling offline group is self-contained.

The original lane markings, dimensions, four alley designs, physics, scoring, input and storage are retained. The texture is blended beneath lane markings; pins and ball now use clear-coated physical materials. A failed texture load leaves the original procedural lane intact.

Browser check: all four alleys rendered at 375×740 without JavaScript errors. A raw test throw completed and stored a five-pin roll. Physical iPhone GPU performance still needs a device check.
