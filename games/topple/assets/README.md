# Topple Fair material pass

Four local 512px textures add photographic grass, wood grain, cloth weave and fine brushed metal. Grass and metal were generated specifically for this game; wood/fabric are local copies of the Get Out material source. Generation prompts are recorded alongside the assets.

Original scene geometry, seeded decorative placement, physics engine, procedural level bank/generator, target colors and emblems remain intact. Existing painted textures are retained beneath subtle material detail and are the fallback if a texture fails. Can labels and the stand gain coated physical finishes. No extra geometry or real-time effects were added.

This is a materials refinement of the current 3D carnival, not a fully photographic scene rebuild. Physical iPhone GPU performance still needs a device check.
